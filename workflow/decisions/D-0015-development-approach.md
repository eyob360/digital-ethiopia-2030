# D-0015: Development approach

**Question:** Should the project use spec-first or prototype-first development?

**Decision:** Use spec-first development.

**Why:** The user chose spec-first during setup. The project now has approved BRDs and significant backend/pipeline behavior that should be planned through blueprints and work orders.
