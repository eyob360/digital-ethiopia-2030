# D-0011: Review flag scope

**Question:** Should review-flagged observations only be visible in the MVP, or should operators be able to approve/reject them in the first release?

**Decision:** Review-flagged observations are visible only in the MVP. Approval and rejection workflows are post-MVP.

**Why:** The user accepted the recommendation to defer the human validation interface until after the first release.
