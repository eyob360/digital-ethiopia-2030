# D-0008: URL domain filtering

**Question:** What domains should be considered invalid or blocked during URL filtering?

**Decision:** Use a configurable domain filtering policy that blocks social/media aggregators, search-result pages, URL shorteners, file-sharing pages, login-only sites, and low-signal forums, while allowing official government, regulator, telecom, development-partner, recognized news, and statistics sources.

**Why:** The user accepted the proposed default policy during BRD review.
