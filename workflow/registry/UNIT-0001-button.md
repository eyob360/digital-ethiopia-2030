# UNIT-0001: Button

**Purpose:** Shared shadcn-style button primitive for app actions.

**Interface:** `Button(props)` accepts native button props and an optional `variant`.

**Variants/options:** `primary`, `secondary`; supports default, hover, focus, and disabled states through tokenized classes.
